#Category	                      Risk Profile
#Historical breaches 	             Legendary catastrophe — the 2013–2014 Yahoo breach exposed 3 billion accounts (passwords, birthdates, security questions). This is the largest single breach in history, and it was disclosed #after Verizon's                     acquisition negotiations. Any account created before ~2017 is fundamentally untrustworthy.
#Current security posture            Moderate — TLS everywhere, 2FA available, but infrastructure is aging. Password hashing practices improved post-breach but lag modern standards
#Telemetry                           Moderate — behavioral tracking across Yahoo properties, search logs retained. No cross-web pixel infrastructure like Facebook/Google
#Third-party                         dependency	Low — Yahoo/Bing search powers DuckDuckGo and other privacy engines; some older websites embed Yahoo widgets, but nothing on Google's scale
#Jurisdiction	                     US, CLOUD Act — same as everyone else
#Email forwarding risk               Yahoo Mail allows forwarding rules that can silently exfiltrate mail. Old accounts are high-value targets for credential stuffing attacks
